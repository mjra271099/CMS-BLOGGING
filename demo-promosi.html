SEO bawaan

Tidak perlu plugin SEO

Semua fondasi SEO sudah ada sejak instalasi pertama, termasuk audit yang memberi skor dan saran.

Yang otomatis

  • Meta title & description per halaman
  • Canonical URL
  • Open Graph & Twitter Card
  • Schema.org: BlogPosting, BreadcrumbList, WebSite
  • Sitemap XML otomatis
  • robots.txt yang bisa diatur
  • RSS feed

Yang bisa Anda kendalikan

  • Audit SEO dengan skor per halaman
  • Redirect manager 301 untuk URL lama
  • Permalink legacy Blogger /?p=ID otomatis dialihkan
  • URL artikel /YYYY/MM/slug.html
  • URL label /search/label/<slug>
Keunggulan

Kenapa memilih CMS ini

Dibangun untuk pemilik blog yang ingin cepat, dan untuk pengembang yang butuh struktur rapi.

◈

Multi-blog & multi-user

Satu instalasi, banyak blog. Setiap posting, halaman, kategori, media, widget, dan pengaturan ter-scope per blog.

👥

Peran berlapis

owner, admin, editor, author, contributor — pengguna bisa punya peran berbeda di tiap blog.

🌐

Dua bahasa

Antarmuka Indonesia dan English untuk seluruh halaman depan. Pengunjung bisa berganti lewat tombol ID/EN.

🔒

Keamanan serius

CSRF di semua form, escaping output, sanitasi HTML, hash password modern, cookie HttpOnly/SameSite, dan blokir akses folder sensitif.

⚡

Cepat tanpa berat

Tanpa framework front-end besar. Skrip front-end kecil dan progresif — navigasi dan membaca tetap jalan tanpa JavaScript.

🧩

Mudah dikembangkan

Struktur MVC: Core, Models, Services, Http, Views. Tema folder-based dengan theme.json dan layout.php.

🎬

Integrasi TMDB

Generator artikel film dari TMDB: pencarian, trending, discover per genre, dan pembuatan artikel otomatis.

📬

Newsletter bawaan

Form langganan, daftar subscriber, dan unsubscribe — tanpa layanan pihak ketiga.

♿

Fokus aksesibilitas

Kontras teks diperhatikan, tautan dekoratif dipisah dari pohon aksesibilitas, dan audit axe/Lighthouse dipakai saat pengembangan.

Persyaratan & instalasi

Ringan dan bisa dipasang di shared hosting

Persyaratan minimum

PHP8.1+
Ekstensipdo_mysql, gd, fileinfo, mbstring, json
DatabaseMySQL 5.7+ / MariaDB (InnoDB, utf8mb4)
Web serverApache + mod_rewrite, atau PHP built-in server

Instalasi lewat browser

  1. Unggah folder ke hosting
  2. Buat database & pengguna database
  3. Buka install.php, isi kredensial
  4. Installer membuat skema 25 tabel & mendaftarkan tema
  5. Hapus/kunci kembali install.php

Atau lewat CLI

php bin/console.php install --name="Blog Saya" \
    --url="https://contoh.com/" --username=admin \
    --email=admin@example.com --password=rahasia-kuat-123

php bin/console.php theme:sync
php bin/console.php seed        # contoh artikel (opsional)
php bin/console.php status

Perintah lain: migrate, user:create, cache:clear, help.

Upgrade dari instalasi lama

Migrasi mengupgrade skema lama di tempat, bukan menimpanya. Tabel lama dipertahankan sebagai backup, dan schema_migrations memastikan migrasi aman diulang. Semua URL Blogger lama tetap berfungsi. 

php bin/console.php migrate
php bin/console.php theme:sync
